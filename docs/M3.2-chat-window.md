## 会话模型（host，`src/panel-api.ts`）

- **每篇论文一个会话**：id 确定性 `zotero-paper-<itemKey>`；文献库会话固定
  `zotero-library`。映射持久化 `cache/chat-sessions.json`（papers[] + library）。
- **激活**（`ensureLiveAgent`）：live `agents.get` → 无则 `agents.create({sessionId,
  meta:{cwd}})`（20s 超时），create 失败（id 已持久化）→ `agents.resume`。
- **cwd 链**：body.cwd（client 从 `sessions.list.getSnapshot().byId[sid].cwd` 取，
  同 ui-chat）→ `parentCwdOf`（live agent header → `sessionPersistence.inspect`）。
  没有 cwd 的会话会在 turn 启动时报
  `prompt variable "{{cwd}}" has no value (section "deployment:persona")` —— 必须保证。
- **注入**：首次打开注入论文全文（`buildPaperContext` qa 模式，tokenBudget 截断）
  或库级引导（`LIBRARY_MODE_PROMPT`）；`force:true` 重载。`sendRead:true` 追加
  `READ_PROMPT` 精读指令；`sendIntro:true` 开场白。
- 消息缓存：保留 `src/index.ts` 的 `ctx.on('session/event')` 订阅
  （user/message 仅 source.kind==='user'；chunk 仅 text-delta；
  tool/result 用 callId→name 配对、`!block.isError && !data.error`）。
  只读端点 `GET /chat-messages?sessionId=`；发送 `POST /chat-send`（冷会话自动 resume）。

## 踩坑（本次修复）

1. **面板 openReadChat 重复 POST**：早期版本面板自己 POST /chat-open（无 cwd）创建会话，
   ChatWindow 再 POST（带 cwd）时已 exists→复用，cwd 已丢。修复：面板只
   `dispatchChatOpen`，host 调用收敛到 ChatWindow.openPaper（带 parent+cwd+sendRead）。
2. **create meta.cwd 必须存在**（见上 `{{cwd}}` 错误）；会话目录名= cwd 编码
   （`--D-AIWORK-~65B0~...--`），`_no-cwd` 目录是缺失信号。
3. **zotero_get_item / search / collections 返回值含 undefined 字段** → dsh-tools
   lossless JSON 校验失败（`tool returned invalid output`）。修复：`cleanJson`
   递归清洗三个出口。
4. **内存脏 agent**：web 重启后仍 live 的旧 agent 会遮蔽磁盘清理——清理会话时
   先 kill web 再删 `sessions/<dir>/zotero-paper-*` 与 chat-sessions.json。
5. 事件订阅签名：`session/event` 回调参数是 `(session: Session, event)`（session 是
   对象，用 `.id`），不是字符串。
