## M1–M2 验证的关键事实（Zotero 9.0.6 实测）

1. **Local API 在 Zotero 9+ 默认关闭**：`GET /api/users/0/items` 返回
   `403 text/plain "Local API is not enabled"`；开关 pref =
   `httpServer.localAPI.enabled`（官方源码 server_localAPI.js：`Zotero.Prefs.get('httpServer.localAPI.enabled')`）。
   开启路径：Settings → Advanced → Config Editor → 搜索 `httpServer.localAPI.enabled` → true。
2. **读请求免鉴权**（GET 无 key），写请求（M4）需 `POST /api/local/authorize`（弹窗 Allow/Always
   Allow）取本地 key，且写请求必须带 `Zotero-Server-ID`（否则 428；不匹配 412）；key 在
   `localAPIKeys.json` 持久化。本插件已捕获并回传 Server-ID。
3. **分页**：本地 API 默认不限量，接受 `start/limit`；`Total-Results` 头可读。
   **排序字段用 `creator`（不是 `creators`）**——工具 enum 已按此修正。
4. 本机同时存在 **pdftotext**（MiKTeX/TeXLive）——作为 MinerU 不可用时的降级正文提取。

## 与 zotero-wave-rag / zotero-harvest 的分工

- wave-rag：sqlite 直读 + 语义检索/详情卡/对比（`zotero_search` 等 5 工具），库关闭状态也适用（需它的 dataDir 配置）。
- harvest：文献投喂入库（lit_*），存后触发 wave-rag 重索引。
- 本插件：**运行态 Zotero 的实时数据通路**（Local API 元数据/全文搜索/附件/笔记批注读写）
  + MinerU 精读（表格/公式/图）+ 面板 + 原生对话联动；与前者互补，不做重复。
  PDF 正文：本插件 MinerU（高保真表格公式）→ pdftotext 兜底；wave-rag 也能用 pdftotext，两者可共存。
