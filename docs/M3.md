## 交付内容

### host 面板 API（`src/panel-api.ts`，挂在 `ctx.webServer`，前缀 `/@dsh-external/dsh-zotero/api`）
| 路由 | 用途 |
|---|---|
| `GET /status` / `GET /verify` | 连接健康 + 库/收藏夹概要（M1 基线） |
| `GET /tree[?q=&collection=]` | 库列表（隐藏纯附件行）+ 收藏夹树（depth 缩进显示） |
| `GET /item?key=` | 条目详情（元数据/附件/笔记/批注） |
| `GET /read?itemKey=` | 解析（缓存优先）→ source/字符数/章节标题/预览 |
| `GET /summarize?itemKey=&mode=&query=` | DSH 默认模型概述/定向总结（成功自动沉淀产出物） |
| `POST /inject-context` | **面板→会话**：`{sessionId,itemKey,mode:'meta'\|'qa'}` → host `agents.get(sessionId).inject(...)` 推入当前对话上下文（`mode=qa` 附全文窗口） |
| `POST /start-read` | **开读·唤起Chat**：注入 QA 上下文 + `followup(READ_PROMPT)` 直接发起一次精读轮次（实测 `{ok:true, chars:40304, followup:true}`） |
| `GET /open?key=` | 打开附件（`file://` 路径 → 系统默认阅读器；实测弹出 Enea 博士论文 PDF） |
| `POST /artifacts` `GET /artifacts` `/artifacts/clear` | 产出物区（`<cacheDir>/artifacts.json`，最多 50 条） |
| `GET /config` | 配置快照（secret 掩码） |

### client 面板（`src/client/index.tsx`，React，`conversation.view` slot）
- **库 tab**：连接状态（绿点/黄点 + 文案）、检索框（qmode=everything 全文）、114 收藏夹下拉（缩进树）、最近 40 条真实库条目（隐藏 attachment 行）；点击条目 → 详情卡（作者/年份/期刊/DOI/标签/摘要 + 附件徽章）＋ 四个动作按钮：
  「送入当前对话」「送入全文·精读问答（QA）」「读全文」「概述」
- **产出物 tab**：类型徽章（read/summary）+ 标题 + 内容预览 + 复制 + 清空（读全文/概述自动沉淀）
- **设置 tab**：配置快照（secret 掩码），提示修改后重载生效

### 踩过的坑（记录给后续）
- `conversation.view` slot 的组件契约是 **React 组件**（`slot.register({...}, Component)`），
  scaffold 生成的 `component: () => ({render})`（vanilla 形态）只适用于其它 slot 类型——最初面板点开为空白，已改 React。
- webserver 的 `req` 是流式 `IncomingMessage`：POST 必须自读 body（`readBody` helper）。
- Local API 附件 = 302 `file://` 重定向（M2 已处理）。
